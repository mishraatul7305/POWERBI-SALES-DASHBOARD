# POWERBI-SALES-DASHBOARD 
 
 📊 Sales Dashboard (Power BI)

This project is an interactive Power BI Sales Dashboard designed to analyze sales data and provide meaningful business insights through visualizations.

🔹 Dashboard Features
📦 Product-wise Sales Analysis
👥 Customer Segment Analysis (Consumer, Corporate, Home Office)
💳 Payment Mode Analysis (Cards, COD, Online)
📈 Sales Distribution by Product
🎯 Interactive Filters and Visualizations
📊 Easy-to-understand Business Insights
🛠️ Tools Used

Power BI
Microsoft Excel / CSV Dataset
Data Cleaning
Data Visualization
DAX (if used)
Power Query

📌 Key Insights
Compare sales across different customer segments.
Analyze payment mode preferences.
Identify high-performing products.
Monitor overall sales trends through interactive charts.
